# If you have write access to the repo and would like to push a file that will be handled by Git LFS, run
```git config lfs.url https://mosim-mod-lfs.sebastianw.tech/MoSim-Modding-Fun/MoSim-Reefscape-Public```

You will need to create a [Personal Access Token](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens) under the Org, with this specific repo (preferrably). It will need "Content" permissions with "Read-and-Write" access.
